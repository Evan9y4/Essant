This is a small report about the programming language Essant

Regex experessions:

Numbers: [0-9]+(\.[0-9]+)?
One or more of any numbers which can be optinally followed by a dot for decimals followed by one or more numbers

Strings: "[^"]*"
One quote followed by zero or more of any character that isn't a quote, until we hit a quote
In the event that there ir no second quote, that is handled in the test cases file "tester.Essant"

Identifiers: [A-Za-z_][A-Za-z0-9_]*
After a lower/uppercase letter or an underscore, follow with zero or more lowercase/uppercase letters, numbers, and underscores

The currently supported keywords are: if, else, or, and, for, while, true, false, var, null, print, return. 
The assignment wasn't super descriptive on what kinds of keywords to have, so I used all of the keywords that I thought were essential.

I'm a little unsure what is meant by "design choices compared to Lox", so I'll just go over a bunch of similarities and differences.
Strings are denoted with ""
Comments are denoted with //
Essant currently doesn't support escape sequences in strings (This might change in the future).
Is missing some keywords that Lox or other programming languages have: super, this, fun, class, def, printf, public, private, etc
